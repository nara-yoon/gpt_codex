# FileNameSEO

`FileNameSEO.vbs`를 더블클릭하면 설치 없이 앱 창이 열립니다. PowerShell 창은 표시되지 않습니다.

- 모든 파일 형식을 대상으로 하며, **파일 내용과 확장자는 변경하지 않습니다**.
- `기존 파일명을 SEO 형식으로 정리`는 공백을 하이픈으로 바꾸고, 특수문자를 제거하고, 확장자를 소문자로 유지합니다.
- `SEO 키워드로 새 이름 만들기`는 입력한 키워드와 순번으로 이름을 만듭니다. 예: `seoul-cafe-01.jpg`.
- 같은 이름이 이미 있으면 `-02`, `-03` 등을 붙여 충돌을 피합니다.
- 하위 폴더 포함 여부를 선택하고, 표에서 변경안을 확인한 뒤 실행하세요.
- 실행 직후에는 **마지막 변경 되돌리기**를 사용할 수 있습니다. 이후 다른 이름 변경이나 파일 이동으로 대상이 바뀐 경우에는 되돌리기가 일부만 실행될 수 있습니다.

SEO 팁: 파일명은 짧고 구체적인 영문 소문자와 하이픈을 권장합니다. 실제 웹사이트에서는 이미지의 의미를 설명하는 `alt` 속성도 별도로 작성해야 합니다.
